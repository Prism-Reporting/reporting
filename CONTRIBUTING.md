# Contributing

Thanks for your interest in `reporting`.

## Current contribution policy

This project is still in a very early stage, and we are not accepting external pull requests at this moment.

- Please do not open unsolicited PRs for code changes.
- If you hit a bug, missing capability, or integration blocker, open an issue instead.
- If a proposed change is especially important, maintainers may choose to invite follow-up contribution later, but that is not the default workflow right now.

## When to open an issue

Issues are welcome for:

- bugs
- missing capabilities you need for adoption
- integration blockers
- confusing docs or unclear behavior

Before opening a new issue:

- search for an existing issue first
- include a clear title and short summary
- add reproduction steps when reporting a bug
- explain your use case when requesting a missing capability

## Review and merge policy

All changes merged into `main` should:

- go through pull request review
- pass CI
- respect CODEOWNERS review requirements

Direct pushes to `main` should be restricted in GitHub branch protection settings.

## Security reports

This repository does not currently publish a private disclosure channel. If you are comfortable reporting an issue publicly, open a GitHub issue with enough detail to reproduce the problem. See [SECURITY.md](SECURITY.md) for the current policy.
